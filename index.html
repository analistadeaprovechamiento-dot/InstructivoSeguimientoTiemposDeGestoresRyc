🛠️ Manual de Instrucciones: Seguimiento y Novedades

Proceso estandarizado para la gestión de novedades en visitas y seguimiento diario.

⏱️ Fase 1: Obtener Hora de Creación (AI/AJ) ▼

Este procedimiento utiliza Google Apps Script para extraer la fecha y hora de creación de los archivos vinculados en la columna de enlaces.

/****************************************************
* MENÚ
****************************************************/
function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu("⏱ Metadata Archivos")
    .addItem("Procesar fechas (AI/AJ)", "procesarFechasArchivos")
    .addToUi();
}

/****************************************************
* FUNCIÓN PRINCIPAL
****************************************************/
function procesarFechasArchivos() {
  const hoja = SpreadsheetApp.getActive().getSheetByName("PLANTILLA");
  if (!hoja) {
    SpreadsheetApp.getUi().alert("❌ No existe la hoja PLANTILLA");
    return;
  }

  const ultimaFila = hoja.getLastRow();
  if (ultimaFila < 2) return;

  const data = hoja.getRange(2, 1, ultimaFila - 1, hoja.getLastColumn()).getValues();

  const COL_ENLACE = 30; // AE → columna 31 → índice 30 (0-based)
  const COL_FECHA = 34; // AI → columna 35 → índice 34
  const COL_HORA = 35; // AJ → columna 36 → índice 35

  const salida = [];

  for (let i = 0; i < data.length; i++) {
    let enlace = data[i][COL_ENLACE];

    // Si no hay enlace o ya tiene datos → saltar
    if (!enlace || (data[i][COL_FECHA] && data[i][COL_HORA])) {
      salida.push([data[i][COL_FECHA], data[i][COL_HORA]]);
      continue
    }

    try {
      // Extraer FILE ID de cualquier tipo de URL
      const fileId = extraerFileId(enlace);
      if (!fileId) {
        salida.push(["ID no válido", ""]);
        continue;
      }

      const file = DriveApp.getFileById(fileId);
      const fechaCreacion = file.getDateCreated();

      const fecha = new Date(fechaCreacion);
      const fechaStr = Utilities.formatDate(fecha, "GMT-5", "yyyy-MM-dd");
      const horaStr = Utilities.formatDate(fecha, "GMT-5", "HH:mm:ss");

      salida.push([fechaStr, horaStr]);

    } catch (e) {
      salida.push(["Error", ""]);
    }
  }

  // Escribe AI (fecha) y AJ (hora)
  hoja.getRange(2, COL_FECHA + 1, salida.length, 2).setValues(salida);
}

/****************************************************
* EXTRAER ID DEL ENLACE
****************************************************/
function extraerFileId(url) {
  if (url) return null;

  const regex =
    /[-\w]{25,}/; // Extrae cualquier ID válido

  const match = url.match(regex);
  return match ? match[0] : null;
}

Explicación Paso a Paso del Apps Script

  1. **`onOpen()` (Menú):** Esta función se ejecuta automáticamente al abrir la hoja de cálculo y crea el menú "⏱ Metadata Archivos" con la opción para iniciar el proceso.
  2. **`procesarFechasArchivos()` (Principal):**
    • Busca la hoja "PLANTILLA".
    • Define las constantes de las columnas: COL\_ENLACE (30/AE), COL\_FECHA (34/AI) y COL\_HORA (35/AJ).
    • Itera sobre los datos, revisando si hay un enlace en la columna AE y si las columnas AI/AJ están vacías.
    • Si están vacías, llama a `extraerFileId()` y luego usa `DriveApp.getFileById()` para obtener el archivo.
    • Extrae la fecha de creación del archivo (**`file.getDateCreated()`**) y la formatea a la zona horaria GMT-5.
    • Escribe la fecha y hora formateadas en las columnas AI y AJ, respectivamente.
  3. **`extraerFileId(url)`:** Esta función auxiliar utiliza una expresión regular para aislar y devolver el ID único del archivo de Google Drive a partir de la URL completa.
  • Preparación de la Base: Haz una copia de la base "GESTIÓN DE NOVEDADES VISITAS" y elimina los días que no sean necesarios para el análisis actual.
  • Acceso a Apps Script: Ve al menú Extensiones y selecciona Apps Script.
  • Limpieza del Código: Borra completamente el código que se encuentre en el editor.
  • Implementación del Código: Pega el código completo y haz clic en el icono del disquete (Guardar proyecto).
  • Actualizar Hoja: Regresa a la copia de la base de datos y presiona F5 para recargar y refrescar la hoja.
  • Ejecutar el Proceso: Aparecerá un nuevo menú llamado "⏱ Metadata Archivos" en la parte superior. Haz clic en él y selecciona "Procesar fechas (AI/AJ)". (La primera vez requerirá permisos).
  • Validación de Fechas: En la columna AK, agrega una nueva columna llamada VALIDACIÓN y usa la fórmula: =AI2=AG2 para verificar si la fecha extraída es igual a la fecha de la visita.
  • Filtrado de Datos: Filtra la columna VALIDACIÓN para mostrar únicamente los valores VERDADERO (TRUE).
  • Transferencia de Datos a "COORDENADAS": En la hoja COORDENADAS:
    • Ve al final de la columna E y pega los códigos BIOC (Columna O) que resultaron del filtro anterior.
    • Pega las Horas (Columna AJ) en la columna F.

🗓️ Fase 2: Creación del Día de Seguimiento ▼

Pasos para configurar la hoja de seguimiento individual de cada inspector.

  • Seleccionar Hoja de Inspector: En la hoja de cálculo de cada inspector, crea la estructura para el nuevo día de revisión.
  • Copiar Estructura: Copia y pega las primeras 5 filas del día inmediatamente anterior.
  • Actualizar Fecha: Da doble clic en la primera fila del nuevo día para actualizar la fecha a la fecha actual de revisión.
  • Limpiar Campos: Suprime la información en las columnas A, H, K y L del nuevo bloque.
  • Filtrar Base Original: Ve a la base original de visitas y aplica dos filtros:
    • Filtra por el Día que vas a revisar (Columna N).
    • Filtra por el Inspector (Columna M).
  • Organizar la Hora: En la columna de Hora (AH), aplica un filtro para organizar los datos de Menor a Mayor.
  • Pegar BIOC y Datos:
    • Copia los códigos BIOC (Columna O) y Pégalos en el día que estás creando en la hoja del inspector.
    • Copia desde el segundo BIOC las columnas B hasta la J y Pégalas hasta el final de los BIOC.
  • Formato Unificado: Asegúrate de que todo tenga la misma tipografía y los bordes correctos.
  • Cálculo y Llenado de Resumen (M y N): Completa la información del resumen del día:
    • Visitas Asignadas: Consulta en la base IMPRESIÓN VISITAS.
    • Visitas Realizadas: Cantidad de códigos BIOC encontrados para ese día.
    • Visitas Devueltas: Resta de (Visitas Asignadas - Visitas Realizadas).
    • Efectividad: Porcentaje que resulta de (Visitas Realizadas / Visitas Asignadas).

🔍 Fase 3: Realizar el Seguimiento y Auditoría ▼

Proceso de auditoría y documentación de las visitas del inspector.

  • Recopilar Reportes: Localiza inmediatamente todos los reportes publicados en los chats "REPORTE INSPECTORES" y el grupo de WhatsApp "SURVEY 123".
  • Relacionar Soportes: Relaciona estos reportes en la columna Soportes (Columna L), asegurándote de que coincidan con el rango horario de las visitas.
  • Verificar Formato: Confirma que el texto en la columna Soportes mantenga el mismo formato del día anterior (típicamente letras grises).
  • Identificar Puntos de Auditoría: Identifica cualquier celda en la columna F o G que esté subrayada en amarillo. Estas son las novedades o brechas de tiempo que debes auditar.
    ⚠️ **Excepción:** El único intervalo de tiempo amarillo permitido sin justificación es la hora de almuerzo (una hora).
  • Complementar con Google Maps: Utiliza el enlace de Google Maps para calcular el tiempo real de traslado (en minutos) entre la visita anterior y la actual.

    Agrega la siguiente frase como soporte: "Se evidencia que hay X minutos de la visita anterior a la visita actual".

  • Redactar Observación: En la columna Observación, redacta un comentario indicando claramente si:
    • Hay una Novedad (ej: "Hay una Novedad: el tiempo no está justificado").
    • El tiempo Está Justificado (ej: "El tiempo está Justificado por reporte de almuerzo").
    ✅ Importante: Usar las palabras NOVEDAD o ESTÁ JUSTIFICADO activa un formato condicional que clasifica y da color (Verde o Rojo) a la fila automáticamente.
  • Cerrar el Día: Una vez finalizada la revisión y auditoría del día, marca en la esquina inferior derecha el texto "OK RVDO".
  • Transferir Novedades: Dirígete al Panel de Coordinación y haz clic en el Paso 4. Esto automatizará la transferencia de todas las novedades a la Hoja de Novedades.
  • Clasificación Final: En la Hoja de Novedades, lo único restante es clasificar el tipo de novedad agregada.

// PASO 1: TRAER VALORES DESDE PLANTILLA
// ------------------------------------------------------
function traerValoresDesdePlantilla() {
  const UI = SpreadsheetApp.getUi();
  const NOMBRE_HOJA_COORD = "CORDENADAS";
  const URL_PLANTILLA = "https://docs.google.com/spreadsheets/d/1HyBS8p-fhh4c8yvoeBLX4Tc1gW7fdWsRrf-4EurwydY/edit";
  const NOMBRE_HOJA_PLANTILLA = "PLANTILLA";
 
  try {
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    const hojaCoord = ss.getSheetByName(NOMBRE_HOJA_COORD);

    if (!hojaCoord) {
      UI.alert(`⚠️ Error Crítico: No se encontró la hoja local '${NOMBRE_HOJA_COORD}'. Asegúrate de que el nombre sea exacto.`);
      return;
    }

    const plantillaSS = SpreadsheetApp.openByUrl(URL_PLANTILLA);
    const hojaPlantilla = plantillaSS.getSheetByName(NOMBRE_HOJA_PLANTILLA);

    if (!hojaPlantilla) {
        UI.alert(`⚠️ Error Crítico: No se encontró la hoja remota '${NOMBRE_HOJA_PLANTILLA}'.`);
      return;
    }
   
    const ultimaFilaCoord = hojaCoord.getLastRow();
    if (ultimaFilaCoord < 2) {
      UI.alert("ℹ️ La hoja CORDENADAS está vacía o solo tiene encabezados.");
      return;
    }
    const datosCoord = hojaCoord.getRange(2, 1, ultimaFilaCoord - 1, 1).getValues();

    const ultimaFilaPlantilla = hojaPlantilla.getLastRow();
    if (ultimaFilaPlantilla < 2) {
      UI.alert("ℹ️ La hoja PLANTILLA remota está vacía o solo tiene encabezados.");
      return;
    }
    const datosPlantilla = hojaPlantilla.getRange(2, 15, ultimaFilaPlantilla - 1, 18).getValues();

    const resultados = [];
    let contadorCoincidencias = 0;

    for (const fila of datosCoord) {
      const codigo = fila[0] ? String(fila[0]).trim() : "";
     
      if (!codigo) {
        resultados.push([""]);
        continue;
      }

      const coincidencia = datosPlantilla.find(r =>
        String(r[0]).trim() === codigo && r[17] !== ""
      );

      if (coincidencia) {
        resultados.push([coincidencia[17]]);
        contadorCoincidencias++;
      } else {
        resultados.push([""]);
      }
    }

    hojaCoord.getRange(2, 2, resultados.length, 1).setValues(resultados);
    UI.alert(`✅ Datos de PLANTILLA actualizados en columna B de CORDENADAS. ${contadorCoincidencias} valores encontrados.`);
   
  } catch (err) {
    const mensajeError = err.message.includes("You do not have permission")
        ? "Error de Permisos: No tiene acceso al archivo de Plantilla. Verifique los permisos de compartido."
        : err.message;
       
    UI.alert("⚠️ Error al traer valores: " + mensajeError);
    Logger.log("Error detallado en Paso 1: " + err.stack);
  }
}

// PASO 2: EXTRAER COORDENADAS DESDE ENLACES
// ------------------------------------------------------
function extraerCoordenadasDesdeEnlaces() {
  const UI = SpreadsheetApp.getUi();
  const NOMBRE_HOJA_COORD = "CORDENADAS";

  try {
    const hojaCoord = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(NOMBRE_HOJA_COORD);
    if (!hojaCoord) {
      UI.alert(`⚠️ Error Crítico: No se encontró la hoja local '${NOMBRE_HOJA_COORD}'. Asegúrate de que el nombre sea exacto.`);
      return;
    }

    const ultimaFila = hojaCoord.getLastRow();
    if (ultimaFila < 2) {
      UI.alert("ℹ️ La hoja CORDENADAS está vacía o solo tiene encabezados.");
      return;
    }

    const enlaces = hojaCoord.getRange(2, 2, ultimaFila - 1, 1).getValues();
    const resultados = [];

    const regex = /(?:[?q=]|[@/d/])?\s*(-?\d+\.\d+)[+, ]+(-?\d+\.\d+)/;

    for (const fila of enlaces) {
      const enlace = fila[0] ? String(fila[0]).trim() : "";
     
      if (!enlace) {
        resultados.push([""]);
        continue;
      }

      const match = enlace.match(regex);
      if (match) {
        const lat = parseFloat(match[1]);
        const lon = parseFloat(match[2]);
        if (!isNaN(lat) && !isNaN(lon)) {
            resultados.push([`${lat.toFixed(6)},${lon.toFixed(6)}`]);
        } else {
          resultados.push([""]);
        }
      } else {
        resultados.push([""]);
      }
    }

    hojaCoord.getRange(2, 3, resultados.length, 1).setValues(resultados);
    UI.alert("✅ Coordenadas extraídas correctamente (columna C).");
  } catch (err) {
    UI.alert("⚠️ Error al extraer coordenadas: " + err.message);
    Logger.log("Error detallado en Paso 2: " + err.stack);
  }
}

// PASO 3: GENERAR ENLACES DE GOOGLE MAPS
// ------------------------------------------------------
function generarEnlacesGoogleMaps() {
  const UI = SpreadsheetApp.getUi();
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const hojas = ss.getSheets();
 
  const HOJAS_OBJETIVO = ["JUAN", "GERMAN", "FRANQUI", "SANTIAGO"];
 
  const COLOR_OBJETIVO = "#fff0db";
  const COLUMNA_COORDENADAS = 3;
  const COLUMNA_COLOR = 8;
  const COLUMNA_SALIDA = 8;

  try {
    let contadorHojasAfectadas = 0;

    hojas.forEach(hoja => {
      const nombre = hoja.getName().toUpperCase();
     
      if (!HOJAS_OBJETIVO.includes(nombre)) return;

      const ultimaFila = hoja.getLastRow();
      if (ultimaFila < 3) return;

      const ANCHO_RANGO = COLUMNA_COLOR - COLUMNA_COORDENADAS + 1;
      const rangoDatos = hoja.getRange(2, COLUMNA_COORDENADAS, ultimaFila - 1, ANCHO_RANGO);
     
      const valores = rangoDatos.getValues();
      const colores = rangoDatos.getBackgrounds();
      const resultados = [];
     
      const COLOR_INDEX = ANCHO_RANGO - 1;

      for (let i = 1; i < valores.length; i++) {
        const coordAnterior = valores[i - 1][0] ? String(valores[i - 1][0]).trim() : "";
        const coordActual = valores[i][0] ? String(valores[i][0]).trim() : "";
                const colorCelda = colores[i][COLOR_INDEX];

        if (colorCelda.toLowerCase() === COLOR_OBJETIVO && coordAnterior && coordActual) {
                    const url = `https://www.google.com/maps/dir/?api=1&origin=${coordAnterior}&destination=${coordActual}`;
                    resultados.push([`=HYPERLINK("${url}"; "Ver Ruta en Maps")`]);
        } else {
          resultados.push([""]);
        }
      }
     
      if (resultados.length > 0) {
        hoja.getRange(3, COLUMNA_SALIDA, resultados.length, 1).setValues(resultados);
        contadorHojasAfectadas++;
      }
    });

    UI.alert(`✅ Enlaces de Google Maps (Rutas) generados. Se actualizaron ${contadorHojasAfectadas} hojas de la lista objetivo.`);
  } catch (err) {
    UI.alert("⚠️ Error al generar enlaces: " + err.message);
    Logger.log("Error detallado en Paso 3 (Filtro de Hojas): " + err.stack);
  }
}

// PASO 4: PROCESAR NOVEDADES (Columna E contiene valor de K)
// ------------------------------------------------------

function procesarNovedades() {
  const libro = SpreadsheetApp.getActiveSpreadsheet();
  const hojasOrigen = ["FRANQUI", "JUAN", "GERMAN"];
  const NOMBRE_HOJA_DESTINO = "NOVEDADES";
  const hojaDestino = libro.getSheetByName(NOMBRE_HOJA_DESTINO);
  const ui = SpreadsheetApp.getUi();

  const MAPA_APELLIDOS = {
    "FRANQUI": "FRANQUI PARRA",
    "JUAN": "JUAN ALAPE",
    "GERMAN": "GERMAN CAMACHO"
  };

  if (!hojaDestino) {
    ui.alert("Error", `La hoja '${NOMBRE_HOJA_DESTINO}' no se encontró. Asegúrate de que el nombre sea correcto.`, ui.ButtonSet.OK);
    return;
  }
 
  let filasRegistradas = 0;
  const urlBase = libro.getUrl();
 
  // LÓGICA PARA DETERMINAR LA FILA DE INICIO (Busca última fila con contenido en Columna D)
  const columnaDeReferencia = 4; // Columna D
  const datosColumnaD = hojaDestino.getRange(1, columnaDeReferencia, hojaDestino.getMaxRows(), 1).getValues();
 
  let ultimaFilaReal = 0;
  for (let i = datosColumnaD.length - 1; i >= 0; i--) {
    if (datosColumnaD[i][0] !== "") {
      ultimaFilaReal = i + 1;
      break;
    }
  }

  let filaInicioEscritura = ultimaFilaReal + 1;
  if (filaInicioEscritura <= 1) {
      filaInicioEscritura = 2;
  }

  // LECTURA POR LOTES PARA DUPLICADOS (Columna F)
  let valoresExistentes = new Set();
  if (ultimaFilaReal >= 2) {
    const rangoF = hojaDestino.getRange(2, 6, ultimaFilaReal - 1, 1).getValues();
    rangoF.forEach(fila => {
      if (fila[0]) {
        valoresExistentes.add(String(fila[0]).trim());
      }
    });
  }

  const datosParaEscribir = [];

  // Iterar sobre cada hoja de origen
  for (const nombreHoja of hojasOrigen) {
    const hojaOrigen = libro.getSheetByName(nombreHoja);
   
    if (!hojaOrigen) {
      Logger.log(`Advertencia: La hoja '${nombreHoja}' no se encontró y fue omitida.`);
      continue;
    }
   
    const nombreCompleto = MAPA_APELLIDOS[nombreHoja] || nombreHoja;
    const ultimaFila = hojaOrigen.getLastRow();
    if (ultimaFila < 1) continue;
   
    const rangoOrigen = hojaOrigen.getRange(1, 1, ultimaFila, 11); // Rango A:K
    const datos = rangoOrigen.getValues();
   
    const INDICE_COLUMNA_A = 0;
    const INDICE_COLUMNA_K = 10; // Columna K es el índice 10
    const gid = hojaOrigen.getSheetId();

    // Recorrer las filas del rango
    for (let i = 0; i < datos.length; i++) {
      const valorCeldaA = datos[i][INDICE_COLUMNA_A];
      const valorCeldaK = datos[i][INDICE_COLUMNA_K]; // 👈 Capturamos el valor de K
     
      const valorCeldaString = String(valorCeldaA).trim();
      const filaActual = i + 1;
     
      const esNovedadRoja = valorCeldaK && String(valorCeldaK).toLowerCase().includes("novedad");

      if (esNovedadRoja) {
       
        if (!valorCeldaString || valoresExistentes.has(valorCeldaString)) {
           continue;
        }
       
        valoresExistentes.add(valorCeldaString);

        // --- PREPARACIÓN DE DATOS PARA ESCRITURA POR LOTES ---
       
        // Columna D: Nombre completo
        const valorD = nombreCompleto;
       
        // Columna E: Contenido de K (¡NUEVO!)
        const valorE = valorCeldaK;
       
        // Columna F: Contenido de A
        const valorF = valorCeldaA;
       
        // Columna G: Hipervínculo
        const referenciaCelda = `A${filaActual}`;
        const etiquetaHipervinculo = `Ir a ${nombreHoja} (${referenciaCelda})`;
        const urlHipervinculo = `${urlBase}#gid=${gid}&range=${referenciaCelda}`;
        const formulaHipervinculo = `=HYPERLINK("${urlHipervinculo}"; "${etiquetaHipervinculo}")`;
       
        // Acumular [D, E (valor K), F, G]
        datosParaEscribir.push([
          valorD,             // Columna D
          valorE,             // Columna E (¡Ahora lleva el valor de K!)
          valorF,             // Columna F
          formulaHipervinculo // Columna G
        ]);
       
        filasRegistradas++;
      }
    }
  }
 
  // 2. ESCRITURA FINAL POR LOTES
  if (datosParaEscribir.length > 0) {
    const columnaInicio = 4; // Columna D
    const numFilas = datosParaEscribir.length;
    const numColumnas = 4; // D, E, F, G
   
    hojaDestino.getRange(filaInicioEscritura, columnaInicio, numFilas, numColumnas).setValues(datosParaEscribir);
  }
 
  if (filasRegistradas > 0) {
    ui.alert("Proceso Completado", `¡Éxito! Se han encontrado y registrado ${filasRegistradas} nuevas novedades en la hoja "${NOMBRE_HOJA_DESTINO}".`, ui.ButtonSet.OK);
  } else {
    ui.alert("Proceso Completado", `No se encontraron nuevas celdas que cumplan la condición ("novedad" en Columna K).`, ui.ButtonSet.OK);
  }
}

Explicación Detallada del Apps Script del Panel de Coordinación

Función onOpen()

  • Propósito: Crea el menú principal "🧭 Panel de Coordinación" que aparece en la barra de la hoja de cálculo, organizando las cuatro funciones de automatización.

1️⃣ traerValoresDesdePlantilla (Paso 1)

  • Acción: Conecta con una hoja de cálculo remota (`URL_PLANTILLA`).
  • Lógica: Busca coincidencias entre los códigos BIOC de la hoja local "CORDENADAS" (Columna A) y los códigos BIOC en la hoja remota "PLANTILLA".
  • Resultado: Si encuentra una coincidencia, trae un valor específico de la hoja remota (que contiene el enlace de ubicación) y lo pega en la Columna **B** de la hoja **"CORDENADAS"**.

2️⃣ extraerCoordenadasDesdeEnlaces (Paso 2)

  • Acción: Procesa los enlaces de Google Maps que se acaban de pegar en la Columna B de **"CORDENADAS"**.
  • Lógica: Utiliza una expresión regular (`regex`) para analizar cada URL y extraer la latitud y longitud.
  • Resultado: Escribe la coordenada en formato Latitud,Longitud (ej: `-12.3456,78.9012`) en la Columna **C** de la hoja **"CORDENADAS"**.

3️⃣ generarEnlacesGoogleMaps (Paso 3)

  • Acción: Crea enlaces de ruta entre visitas en las hojas individuales de los inspectores (JUAN, GERMAN, etc.).
  • Lógica: Recorre las hojas objetivo y verifica si la fila actual tiene el color de fondo específico (`#fff0db`, un color de énfasis en tu seguimiento). Si es así, toma la coordenada de la visita anterior y la actual para construir un enlace de Google Maps con la ruta (`/dir/`).
  • Resultado: Inserta una fórmula **`=HYPERLINK(...)`** en la Columna **H** para que el usuario pueda hacer clic y ver el tiempo de traslado.

4️⃣ procesarNovedades (Paso 4)

  • Acción: Automatiza la recopilación de resultados de la auditoría de seguimiento.
  • Lógica: Itera sobre las hojas de origen (`FRANQUI`, `JUAN`, `GERMAN`) y busca filas donde el valor en la **Columna K (Observación)** contenga la palabra clave **"novedad"**.
  • Mecanismo de Control: Evita duplicados verificando si el BIOC ya fue registrado en la hoja de destino **"NOVEDADES"**.
  • Resultado: Escribe los datos de la novedad (Inspector, contenido de K, BIOC) en las Columnas **D, E, F, G** de la hoja **"NOVEDADES"**, incluyendo un hipervínculo directo a la celda de origen en la hoja del inspector.
